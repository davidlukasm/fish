# Entwürfe

Atelier-Baupläne und ihre erzeugten Genome. Die Oberfläche bietet sie in der Kategorie
„Entwürfe“ an. Nach erfolgreicher Fortpflanzung über mehrere Generationen in mehreren
Aquarien können geprüfte Fische ins Fischregal (`genomes/regal`) aufgenommen werden.

`make starter` baut die Genome aus den Bauplänen beider Verzeichnisse neu.
